# validation/

Your validation checks, starting with the three from Module 7. For each check, write:

| Field | What to write |
|---|---|
| What it checks | the one thing it tests |
| What it found | the result when you last ran it |
| What pass or fail means | what a reader should conclude from each |
| What it cannot see | the kind of mistake it would miss |

Checks that all pass do not prove the pipeline is right. Saying what each check cannot see is part of the grade.
