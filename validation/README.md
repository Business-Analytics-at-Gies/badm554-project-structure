# validation/

Your validation checks, starting with the three from Module 7 (row counts, key uniqueness, and one of your own).
For each check, write:

| Field | What to write |
|---|---|
| What it verifies | the one thing it tests |
| What it found | the actual result when you last ran it |
| What a pass or fail means | what a reader should conclude from each |
| What it is blind to | the failure it cannot see |

A clean set of checks is not the same thing as a correct pipeline. Saying what each check cannot see is part of the
grade.
