# analyses/

One notebook or SQL file per stakeholder question, named for the question (for example
`q1-which-stores-grew.ipynb`). At the top of each:

- **The question**, in the stakeholder's words.
- **The answer**, in one or two sentences, with the number that supports it.
- **The query or code** that produces it, run against the warehouse.
- **What would make the answer wrong**, and how you checked it did not happen.

Every stakeholder question your team framed needs one. The rubric looks for "a specific, supported analysis" for
each.
